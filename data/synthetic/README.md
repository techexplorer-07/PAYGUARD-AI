# Synthetic Data Directory

This directory is designated for **synthetic, simulated, and benchmark datasets** for the PAYGUARD AI prototype.

## Strict Guidelines

1. **No Real Customer Data**: Under no circumstances should real customer records, personally identifiable information (PII), or live banking details be placed in this repository.
2. **Synthetic Generation**: All datasets used for fraud prevention evaluation, behavioral sequence analysis, and intent pattern recognition must be synthetically generated or derived from publicly available academic benchmarks.
3. **Phase Status**: In Phase 1 (Foundation), no datasets are loaded or generated. Data schemas and generator scripts will be introduced in subsequent phases according to the `DEVELOPMENT_PLAN.md`.
